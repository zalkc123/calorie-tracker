# Calorieën Tracker

Een eenvoudige calorieën-tracker in één enkel HTML-bestand. Werkt volledig offline — geen account, geen server. Je gegevens worden lokaal in je browser opgeslagen (localStorage).

## Gebruiken

1. Download `index.html`.
2. Open het bestand in een webbrowser (dubbelklikken is voldoende).

## Functies

- **Automatische caloriewaarden**: terwijl je typt krijg je suggesties uit een ingebouwde voedingsmiddelendatabase (per standaardportie) en wordt de kcal-waarde automatisch gevuld
- **Dagelijkse calorie-invoer** per maaltijd (ontbijt, lunch, diner, snack)
- **Dagdoel instellen** met voortgangsbalk en resterende calorieën
- **Navigeren tussen dagen** (vandaag, gisteren, en eerder)
- **Weekoverzicht** met staafdiagram van de afgelopen 7 dagen
- **Exporteren/importeren** van je gegevens als JSON-backup
- Alles blijft lokaal opgeslagen in je browser
